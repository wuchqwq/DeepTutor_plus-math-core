# Bounded counterexample feedback

This change depends on the local reviewed PR23–26 integration
`8fb402ec173306f1e137145e175b042c210566a5`.

The existing step checker can record a genuine `COUNTEREXAMPLE` with
`all_constraints_exactly_checked`, the accepted equality, mathematical scope,
finite point and typed tool receipts. This feedback projects those receipts
through the existing publication owner. It does not change the checker,
tools, budgets, selector strategy or source authority.

The new finite contract is `bounded_counterexample_feedback_v1`; its act is
`local_counterexample`. It binds the current accepted row and exact claim,
source, episode, current mathematical basis, checked revision and complete
support receipt. The canonical sentence only says that the two sides of
submitted equality N are unequal at the displayed, already verified point.
The point must satisfy every applicable explicit premise and definition;
the nonzero residual must have its own matching typed substitution receipt.
It can be selected alongside an independently authorized existing operation.

Every receipt is re-resolved by the existing acceptance fence. An invalid,
foreign or stale selected grant rejects the complete publication. This new
contract is separate from the original neutral clarification and local
confirmation contract, and cannot impersonate either. Historical stored
receipts remain unchanged and replay without running tools or a provider.

The first contract deliberately supports only the existing bounded real
polynomial grammar and its genuine finite witnesses. It publishes domain
variable values only, never the computed definition quantities. It does not
publish independent numeric left/right values: the checker records their
nonzero difference, rather than two separate side-value receipts. It creates
no error cause, missing-term diagnosis, step-location judgment, stage
completion, mastery judgment or complete answer.

Sources containing a target, objective or any authored answer / answer
candidate / final answer are outside this first witness-disclosure contract,
even if they have a successful counterexample. The full S4 problem retains
all its resources and constraints; it is not narrowed to make this feedback
available. A smaller existing S4 algebra structure with no target/answer can
be supported when all its existing constraints and definitions are checked.

UNKNOWN, timeout, unsupported scope, uncertain claims or premises, absent
witness, missing applicable receipts and stale evidence never become error
feedback. They keep the existing authorized offers, including neutral
clarification when available. No additional mathematical tool executes during
publication acceptance or replay, and no retry changes UNKNOWN into false.

Automated controls use the real existing checker and test native publication,
rejection and byte-preserving replay. Offline forced offer selection proves
this boundary only. A separate real-provider sample records actual model
selection and usage; neither establishes a general success rate or human
learning outcome.
